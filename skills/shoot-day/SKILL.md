# shoot-day

**Promise:** one phone session, in order, no re-setting up, done in ≤90 minutes.

## Read first
- `skills/content-week/references/video-rules.md` → default setup is the slouch-to-lift: phone leaning on a mug at the kid's head height, side-on, don't move it between before and after.
- `DIGIROO-brief.md` §12 (settings) and §3 P3 (her constraints).
- All `media/<week>/post-cards/*.md` for the week (or the cards she pastes).
- `templates/shoot-card.md`.

## Steps
1. **Extract every shot** from every card: post id, shot #, framing, what happens, who's in it (kid / Antonia / hands only), location (couch, kitchen table, car, outdoors, desk), props, seconds.
2. **Group** by location → then by talent (hands-only and Antonia-only first, kid blocks last and shortest; kids have a 20-minute attention budget) → then by camera setup (phone on stand vs. handheld selfie).
3. **Order blocks** to minimise moves: start where the light is best at her shoot time; outdoor/car block last.
4. **Estimate minutes:** 2 min per hands-only shot, 3 min per talking shot (2 takes), 4 min per kid shot, +5 min per location change, +10 min setup, +10 min B-roll. If total >90, flag the lowest-priority post (pillar D or E first) as "shoot next week" and recompute.
5. **Continuity:** one outfit for everything marked same-day; note which posts should look like different days (change top only).
6. **B-roll list:** always include the 4 defaults in the template, plus anything a card's format file lists under "Proof".
7. **Props checklist:** units (both colours), iPad charged, box (for unboxing), any comment screenshots printed/opened, code card for affiliate posts.
8. **Write** `media/<week>/shoot-card.md`. Then tell her: total minutes, which block needs the kid, the one thing to do before she starts (charge the phone, wipe the lens).

## Rules
- Phone only. Never require a tripod beyond "lean it against a mug".
- If a card's shot can't be filmed with what's in the checklist, rewrite the shot, don't add gear.
- Record every take; trimming is `edit-cuts`' job, not hers.
