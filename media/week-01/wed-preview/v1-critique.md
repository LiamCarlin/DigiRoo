# Wednesday cut v1 — what's wrong with it (self-review before the segment analysis)

Watched against what wins in the niche, v1 has six problems. v2 fixes them using the rules in `skills/content-week/references/video-rules.md`.

1. **No problem shown.** It opens on a girl carrying the case. Winning kids-posture videos open on the problem (a hunched kid, head down), then fix it. The product with no "before" is an ad.
2. **No spoken hook.** The first 1.5 s has only a burned-in "BOUGHT A NEW" caption from the source, which means nothing on its own. The banner on top is the only hook, and text alone doesn't stop a scroll.
3. **Three unrelated videos stitched into one.** Different kids, years, lighting and caption styles; it reads as a compilation. One subject, one setting, one idea per video.
4. **Two caption systems on screen.** The source reels' burned-in captions fight my yellow overlay and top banner. Either strip to clean footage (none exists for these reels) or don't add text over text.
5. **Low source quality.** The car clip is 720p with motion blur; upscaled to 1080 it looks soft next to the end card.
6. **Nothing asked.** 26 s with no on-screen question; the comment prompt lives only in the caption.

Lesson for the skill: re-cutting old posts that already have captions is a last resort. The format-13 "UGC re-cut" needs raw (uncaptioned) clips or it should be dropped for the week.
