# 02 · Before/after in 7 seconds

**Pillar:** C · **Length:** 7–12 s · **Hook type:** Visual anomaly / reveal

**Use when:** You need a quick product post and have 2 clips. Great for Stories and ads later.

## Structure (beats)
[0–3 s] 'Before': kid hunched, head down, text 'iPad neck'. Hard cut. [3–7 s] 'After': stand up, screen at eye level, kid upright, text 'DigiRoo'. [7–10 s] Hold + CTA.

## Script skeleton
```
(no voice; sound + text only)
Text 1: 'tablet neck'  Text 2: 'tablet neck, elevated'
```

## Shot list skeleton (phone only)
1. Side profile of kid with iPad flat, 4 s
2. Same side profile with DigiRoo raised, 4 s
3. Optional: slow hand lift transition, 3 s

## On-screen text pattern
before → after → 'Screen Time, Elevated.'

## Why it works
Side profile makes the head angle undeniable; short enough to loop, which boosts completion rate.

## How DigiRoo uses it
Film every before/after from the side at kid-head height. Loop-friendly: end on the same frame you started on.
