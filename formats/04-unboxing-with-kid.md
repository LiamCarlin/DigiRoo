# 04 · Unboxing with a kid

**Pillar:** C · **Length:** 25–40 s · **Hook type:** Demo cold-open

**Use when:** You have a sealed unit and a kid who'll react. Also the easiest UGC brief for affiliates and customers.

## Structure (beats)
[0–2 s] Kid's hands tearing the box, text 'she's been waiting for this'. [2–12 s] Pull out, colour reaction, iPad goes in. [12–25 s] Kid discovers the stand: lifts, tilts, sets it on the floor/table, sits up. [25–35 s] Kid verdict (one unscripted line). CTA.

## Script skeleton
```
(mostly unscripted; prompts)
Mom: 'What do you think it does?'
Kid: …
Mom: 'Try pulling that up.'
Kid: …
Mom: 'Where would you use it?'
```

## Shot list skeleton (phone only)
1. Top-down of box opening, 5 s
2. Kid face reaction, 3 s
3. Hands fitting the iPad, 5 s
4. Kid finding the stand, side angle, 8 s
5. Kid using it, wide, 5 s
6. Kid's one-liner, 4 s

## On-screen text pattern
'she's been waiting for this' / 'wait for the stand' / kid quote as caption

## Why it works
Kids' genuine reactions are the highest-trust UGC; the stand reveal is a built-in 'wait for it'.

## How DigiRoo uses it
Save the kid's unscripted line; it becomes next week's hook. Send this exact shot list to affiliates and customers as the UGC brief.
