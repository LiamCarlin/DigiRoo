# 01 · POV: mom spots the slouch

**Pillar:** A · **Length:** 12–20 s · **Hook type:** POV / self-identification

**Use when:** You have a kid, a couch and 10 minutes. The reliable weekly banker.

## Structure (beats)
[0–1.5 s] Static shot of kid folded over the iPad, text 'POV: you look over and see this'. [1.5–6 s] Mom reaction (dead stare / sigh), no words. [6–12 s] Hand enters, pops the DigiRoo stand up, screen rises, kid sits up without being told. [12–18 s] Same framing, kid upright, text 'and now I don't have to say sit up'. CTA line.

## Script skeleton
```
(spoken, optional, can be text-only)
'Every parent has seen this.' [slouch]
'Nobody wants to say sit up fifteen times.' [reaction]
'So the screen comes up instead.' [lift]
'DigiRoo. It's in my bio.'
```

3. Hands + case: stand lifts, same angle as shot 1, 5 s

Instant self-identification; before/after inside one framing; zero talking needed so it works with any trending sound.
