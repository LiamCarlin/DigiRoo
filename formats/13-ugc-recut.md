# 13 · UGC re-cut (from the Drive folder)

**Pillar:** C · **Length:** 15–30 s · **Hook type:** Social proof / borrowed voice

**Use when:** You have customer or influencer clips in the Drive folder and no time to shoot.

## Structure (beats)
[0–2 s] New hook text over the strongest 2 s of the UGC. [2–20 s] Best 2–3 UGC moments, trimmed to spoken segments, captions burned in. [20–25 s] End card: product + CTA.

## Script skeleton
```
use the creator's own words; add only an on-screen hook and an end card
```

## Shot list skeleton (phone only)
none new; pick clips with: a visible slouch→lift, a kid reacting, or a parent saying one clear benefit

## On-screen text pattern
hook over first 2 s / creator's words as captions / 'Screen Time, Elevated.' end card

## Why it works
Other parents' voices beat the brand's; re-cutting with a new hook makes old clips feel new.

## How DigiRoo uses it
Run edit-cuts on 2–3 Drive clips per month. Get written permission from each creator to repost (log in media/raw/permissions.md).
