# 06 · Day in the life: screen time edition

**Pillar:** A · **Length:** 25–40 s · **Hook type:** Relatability montage

**Use when:** You want a low-pressure lifestyle post from B-roll you already shot.

## Structure (beats)
[0–2 s] 'Every place my kid uses an iPad in one day.' [2–30 s] 5–7 quick cuts, 3–4 s each, DigiRoo in each: breakfast table, car, waiting room, couch, grandma's, bed. Text label per location. [30–36 s] 'Same case, every room, screen at eye level.' CTA.

## Script skeleton
```
(VO or text)
'Breakfast.' 'Car.' 'Dentist.' 'Couch.' 'Nana's.' 'Bed, allegedly.'
'Same case, every room, screen up where her eyes are.'
```

## Shot list skeleton (phone only)
5–7 clips, 4 s each, kid using DigiRoo in different spots; keep the kid's outfit consistent or label days

## On-screen text pattern
location labels / 'every room, eye level'

## Why it works
Montage = watch time; multi-context demo answers 'where would we even use it'.

## How DigiRoo uses it
Film one location per day across a week with the phone already out; this post makes itself.
